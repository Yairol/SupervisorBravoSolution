# Industrial SCADA System - Full-Stack Implementation

A robust, web-based **SCADA (Supervisory Control and Data Acquisition)** solution developed to manage industrial thermal and electrical processes. The system features a dynamic architecture allowing for device scalability and real-time analytics.

## 🚀 Core Features
* **Dynamic Device Management:** Capability to provision and configure new industrial devices within the system on the fly.
* **Real-time Control:** Direct interaction with hardware to toggle relay states and manage actuators.
* **Advanced Monitoring:** Real-time temperature tracking and interactive data visualization (graphing).
* **Industrial Protocols:** Robust data acquisition via **Modbus RTU**.
* **Automated Reporting:** Generates specialized reports for **Electrical Consumption** and **Thermal Efficiency**.
* **Alarm System:** Real-time alert management for critical process thresholds.

## 🛠️ Tech Stack
* **Backend:** .NET / ASP.NET (utilizing **Background Tasks** for persistent hardware polling).
* **Frontend:** HTML5, CSS3, and JavaScript for interactive dashboards.
* **Communication:** Modbus RTU protocol integration.
* **Database:** [e.g., SQL Server/PostgreSQL] for historical data and automated reporting.

## 📊 Impact
This software centralized the energy and thermal management of the plant, providing actionable insights through automated efficiency reports and reducing response time via its integrated alarm system.
